# 睿选智能决策

面向企业招投标团队的商机发现与投标管理产品，连接项目查找、筛选比较和投标协作，帮助团队发现适合自己的项目，并有序推进投标工作。

## 产品背景

招投标工作中的项目信息、筛选记录和执行进度，往往分散在不同网站、表格和沟通记录中。团队既要花时间查找和整理信息，也要判断项目是否值得参与，并协调后续任务。

睿选智能决策围绕这条工作路径组织功能，让商机发现与投标执行能够衔接起来。

## 核心功能

### 商机发现

通过项目热力图和列表展示招投标机会，结合关键词搜索查看相关项目。先了解区域与行业分布，再进入具体公告核对项目详情。

### 多维筛选

支持按地区、行业、优先级、风险等级、项目金额和发布时间组合筛选，并按发布时间、金额或优先级排序，缩小候选范围，方便比较和安排跟进顺序。

### 投标协作

围绕意向项目组织投标筹划、任务排序、标书分配、答疑澄清和标书审核，把项目筛选后的工作衔接到具体人员与任务。

## 适用对象

- **投标经理**：筛选候选项目，安排任务，跟踪投标进度。
- **部门负责人**：比较项目价值与投入，确定参与顺序，协调团队资源。
- **商务拓展人员**：发现项目线索，查看区域与行业机会，交接后续跟进工作。

## 使用流程

查看项目分布 → 筛选候选项目 → 核对条件并确定参与意向 → 分配投标任务 → 推进答疑与审核

## 产品价值

把找项目、选项目和推进投标放在连续的工作路径中，减少重复整理和交接遗漏，让团队更清楚地掌握关注哪些项目、优先处理什么、由谁继续推进。
